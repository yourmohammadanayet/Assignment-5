# Dev Stack

Dev Stack is a responsive React application that allows users to explore popular development technologies and build their own custom technology stack.

## Features

- Explore development technologies
- Technology data loaded from a JSON file
- Responsive technology cards
- Add technologies to Your Stack
- Prevent duplicate selections
- Remove individual technologies
- Remove all selected technologies
- Dynamic selected card state
- Toast notifications using React Toastify
- Loading state while fetching data
- Responsive desktop and mobile layout

## Technologies Used

- React
- Vite
- Tailwind CSS
- JavaScript
- React Toastify
- JSON
